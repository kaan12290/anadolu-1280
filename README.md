# Anadolu 1280 — Taht ve Toprak

Tarayıcıda çalışan, tek oyunculu tarih ve strateji oyunu.

Bu dağıtım, Anadolu_1280_Web_GitHub.zip içindeki mevcut oyunu değiştirmeden
GitHub Pages için hazırlar. HTML içindeki oyun kodu ve görseller korunmuştur.

## Yayın

GitHub Pages kaynağı: main dalı, /(root) klasörü.
index.html giriş dosyasıdır. Derleme veya paket kurulumu gerekmez.
.nojekyll statik dosyaların doğrudan yayımlanmasını sağlar.

## Kayıtlar

Seferler tarayıcıda yerel olarak saklanır. Başka bir sitedeki kayıtlar yeni
adrese otomatik taşınmaz; oyun içinden JSON dışa/içe aktarma kullanılabilir.

## Teknik yapı

HTML, CSS, JavaScript, SVG ve gömülü görseller. Sunucu veya hesap gerektirmez.
